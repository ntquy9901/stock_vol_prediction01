## Critical findings

### AUD-001 — LSTM-GAT normalization leakage

- Evidence: `src/lstm_gat_hybrid/dataset.py:266-276`, `src/lstm_gat_hybrid/dataset.py:411-470`, `src/lstm_gat_hybrid/train.py:243-259`.
- Finding: feature and target normalizers are fitted on the complete dataset before train, validation, and test subsetting.
- Impact: validation and test distributions influence training transforms; reported generalization metrics are not scientifically valid.

### AUD-002 — Cross-stock samples are not aligned by trading date

- Evidence: `src/lstm_gat_hybrid/dataset.py:215-231`, `src/lstm_gat_hybrid/dataset.py:287-315`.
- Finding: rows are removed independently per ticker and remaining frames are stacked by positional index using `.iloc`.
- Impact: the same position may represent different dates across stocks, producing temporally incoherent graph inputs and targets.

### AUD-003 — Random splitting remains in time-series trainers

- Evidence: `train_simple_lstm_vn30.py:50`, `train_lstm_har_vn30.py:50`, `src/experiment/train_best_lstm.py:115`, `src/experiment/optimize_lstm.py:105`, `src/experiment/optimize_lstm_fast.py:181`.
- Finding: these paths use `torch.utils.data.random_split` for ordered time-series data.
- Impact: metrics generated by these lineages may contain temporal leakage and should not be used in the paper without chronological reruns.

### AUD-004 — Headline directional accuracy is invalid for panel ordering

- Evidence: `src/lstm_gat_hybrid/train.py:166-195`, `src/lstm_gat_hybrid/train_parallel.py:195`, `src/lstm_gat_hybrid/train_parallel_enhanced.py:378,422`, `src/common/evaluation.py:45-49`.
- Finding: day-by-ticker arrays are flattened before applying `np.diff`, causing some transitions to compare different tickers rather than consecutive dates for one ticker.
- Impact: conclusions change materially. The horizon-1 per-ticker gate artifact reports flattened directional accuracy of `72.39%` but per-stock directional accuracy of `33.16%`.

## High-severity findings

### AUD-005 — TimesNet normalization leakage

- Evidence: `src/timesnet_baseline/dataset.py:55-74`, `src/timesnet_baseline/dataset.py:135-145`, `src/timesnet_baseline/dataset.py:255-271`.
- Finding: TimesNet feature and target scalers are fitted before temporal sequence splitting.
- Impact: validation and test observations affect training transformations.

### AUD-006 — TimesNet selects one unspecified CSV

- Evidence: `src/timesnet_baseline/dataset.py:84-93`, `src/timesnet_baseline/train.py:288-300`.
- Finding: the loader uses an unsorted glob and silently selects `csv_files[0]` from a multi-file directory.
- Impact: results depend on filesystem enumeration and may represent one unspecified ticker rather than the documented universe.

### AUD-007 — Repository-wide pytest collection fails

- Observed command: `python -m pytest --collect-only -q`.
- Observed result: 218 tests collected and four collection errors.
- Affected baseline families: `2026-07-08_market_fallback`, `2026-07-18_alignment_loss_baseline`, and `2026-07-18_gated_crossattn_baseline`.
- Finding: generic names such as `model_embedding` and `dataset_embedding` collide through `sys.path` and `sys.modules` when multiple baselines are collected in one process.

### AUD-008 — Smoke gate does not execute successfully

- Observed command: `python -m pytest -m smoke -q`.
- Observed result: four collection errors and 93 deselected tests.
- Additional finding: only one explicit `@pytest.mark.smoke` occurrence was identified; files named `test_smoke.py` without the marker are excluded by `-m smoke`.

### AUD-009 — Default pytest discovery omits the root test suite

- Evidence: `pytest.ini:4-6` defines only `src` and `baselines` under `testpaths`.
- Finding: approximately 26 test files under root `tests/` are not included by the default `python -m pytest` command.

### AUD-010 — Headline model performance is not reproducible yet

- Evidence from seeded per-ticker-gate runs: seed 42 QLIKE `0.5704`, seed 123 QLIKE `0.5488`, and seed 2026 QLIKE `0.5503`.
- Historical headline: QLIKE `0.5473`.
- Finding: no epoch-matched multi-seed comparison against the principal controls is available.
- Impact: the current evidence does not establish a stable improvement over HAR-only or REST-TS.

### AUD-011 — “Best result” claims are contradictory

- Evidence: reports identify per-ticker gate QLIKE `0.5436`, `0.5473`, or `0.5497` as the headline result, while `results/resttext_2026-07-18_014318/results.json` records REST-TS QLIKE `0.5431388`.
- Finding: model ranking is not based on one canonical table with matched seed, epoch, split, dataset, and metric semantics.

### AUD-012 — VN30 universe is not frozen to a reproducible definition

- Finding: current artifacts use 32 tickers and include a stale membership set.
- Impact: the dataset cannot be described unambiguously as VN30 until the study defines a fixed historical cohort, point-in-time membership, or a survivorship-adjusted universe.

## Medium-severity findings

### AUD-013 — Lint gate fails

- Observed command: `ruff check src tests baselines --exclude archive --exclude .agents --exclude .Codex --exclude _bmad --exclude data`.
- Observed result: 947 violations; Ruff identified 583 as auto-fixable.
- Finding categories include unused imports and variables, ambiguous names, excessive line length, multiple statements per line, and executable test logic at module import time.

### AUD-014 — Current coverage cannot be verified

- Finding: pytest collection failure prevents valid repository coverage and diff-coverage measurement against the audited commit.
- Impact: historical `coverage.xml` files cannot substantiate current C0 or C1 gates.

### AUD-015 — Result provenance is incomplete

- Finding: result artifacts do not consistently record Git SHA, data hash, ticker order, split dates, seed, invocation command, environment, complete configuration, and metric-schema version.
- Impact: results cannot be independently reconstructed or reliably pooled into a paper table.

### AUD-016 — Metric writers can persist non-finite values

- Evidence: `src/common/evaluation.py:16-61`, `src/lstm_gat_hybrid/train.py:200-207`, `src/timesnet_baseline/train.py:244-260`.
- Finding: finite-value and minimum-length validation is incomplete, while standard `json.dump` permits `NaN` and `Infinity` by default.

### AUD-017 — TimesNet training lacks reproducibility controls

- Evidence: no Python, NumPy, or Torch seed setup was identified under the active `src/timesnet_baseline` training path.
- Impact: model initialization and shuffled batches are not reproducible.

### AUD-018 — Temporal split validation lacks edge-case guards

- Evidence: `src/common/temporal_split.py:25-118`.
- Finding: validation is incomplete for invalid ratios, empty partitions, unparseable or `NaT` dates, duplicated dates, and mixed timezones.

### AUD-019 — Baseline isolation is not runtime-safe

- Finding: mandatory folder isolation exists for all 23 timestamped baselines, but generic sibling imports allow module resolution to depend on process import order.
- Impact: standalone scripts and repository-wide pytest can execute different module implementations.

### AUD-020 — Required baseline test is missing

- Evidence: `baselines/2026-07-25_news_usefulness_ablation/test/` contains no discoverable `test_*.py` file.
- Impact: downstream ticker-selection evidence is not protected by the mandatory baseline test gate.

### AUD-021 — Objective-news baseline is incomplete

- Finding: `baselines/2026-07-15_objective_news_baseline` contains extraction work but no completed training and matched-control comparison.

### AUD-022 — Statistical inference is absent

- Finding: no canonical confidence intervals, paired or block-bootstrap tests, multiple-comparison handling, or consistent mean-and-standard-deviation tables were identified for claims of model superiority.

### AUD-023 — Project documentation is stale and internally inconsistent

- Evidence: `project-context.md` contains an outdated header date, feature descriptions not representative of the principal trained pipeline, and result/status claims that conflict with newer artifacts.
- Impact: an independent reviewer cannot reliably identify the authoritative configuration and result.

### AUD-024 — Submission package is absent

- Finding: no single canonical result table, IMRAD manuscript, citation-managed bibliography, statistical-analysis artifact, supplementary reproducibility package, or data/code availability statement was identified.
