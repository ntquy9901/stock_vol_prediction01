# docs/reports/ — Summary of Update Reports

Mỗi thay đổi (per CLAUDE.md "Project Quality Rules") sinh 1 report: `<YYYY-MM-DD_HHMM>_summaryOfUpdate_report.md`.

## Format (context-appropriate, không rigid template)
Mỗi report cover (as applicable cho change đó):
- What changed
- Files changed (path → purpose)
- Tests + coverage %
- **Code-review result + actions** (LUÔN required)
- Commands run thật (ghi `Not run` + lý do nếu skip)
- Risks / follow-ups
- Definition-of-Done checklist

Trung thực: chỉ ghi gì thật xảy ra.
