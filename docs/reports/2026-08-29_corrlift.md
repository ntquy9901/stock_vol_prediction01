# Combined corr+lift graph edge (arXiv:2502.15813 §3.2) — 6th HNX h1 edge probe

**Date:** 2026-08-29
**Baseline:** `baselines/2026-08-29_corrlift_ablation`
**Result:** `results/corrlift_ablation/corrlift_ablation_hnx_h1.json`
**Panel/target:** HNX, horizon 1, 154 nodes, 60,028 test observations; 10 epochs (early stop), seeds {42, 123, 2026}, batch 32, GPU.

## 1. What was built
A sixth graph-edge construction replicating the COMBINED linear + non-linear edge of Sonani, Badii & Moin
(2025), "Stock Price Prediction Using a Hybrid LSTM-GNN Model" (arXiv:2502.15813), §3.2, plugged into the
delivered LSTM+GAT volatility pipeline (`masked_rich` / `run_masked_rich`, imported read-only). The combined
adjacency replaces the shipped statistical edge as a clean leave-one-out edge swap; all other pipeline
elements (masked union panel, 5 node features, HAR-X anchor, per-ticker StandardScaler, QLIKE floor, folds,
seeds, 2-hop WeightedGATLayer) are held fixed.

### Paper -> code formula map
| Paper §3.2 element | Code (`corrlift_edge.py`) | Note |
|---|---|---|
| Return `r_t = (P_t - P_{t-1})/P_{t-1}` (Eq. 2) | `daily_returns` (per-ticker `pct_change` on own trading dates) | close from raw HNX OHLCV |
| Pearson `rho_ij` (Eq. 3) | `pearson_corr` (mean-centred cov / std product on co-finite days) | test recomputes independently |
| Linear edge `|rho| > 0.7` | `CORR_THRESH = 0.7` | paper threshold |
| Item = per-stock notable move | `move_events`: `|return| >` stock's TRAIN-median `|return|` | per-stock indicator; a transaction = one trading day |
| `support(X) = P(X)`; `lift(i,j) = support(i,j)/(support(i)support(j))` | `pairwise_lift` (co-observed days) | standard market-basket definitions; supports taken over each pair's CO-OBSERVED transaction set; test recomputes independently |
| Non-linear edge `lift > 1.7` | `LIFT_THRESH = 1.7` | co-move ~70% more than chance |
| Combine (edge if EITHER fires) | `build_corrlift_adjacency` | weight = mean of fired normalised strengths (`|rho|`; `lift-1` MAX-scaled by the largest fired excess), self-loop = 1.0 |

**Leakage control (strict; the paper is silent on this).** The entire graph — returns, correlations,
per-stock move thresholds, supports, lifts — is computed from TRAIN close rows only (`date < D.d_va[0]`, the
first validation target date), then frozen for val/test, mirroring how `masked_rich` fits `adj_vol2pk`
train-only. Every included close row is strictly before every val/test target date, so there is no evaluation
leakage. This boundary is marginally looser than the delivered `adj_corr` / `adj_vol2pk` cut (which uses the
last-train-target row and excludes the ~horizon purge-gap rows); the difference is a handful of rows out of
thousands, touches no val/test data, and has nil effect here (the graph is near-empty regardless). A unit
test poisons every post-cutoff row with extreme values and asserts the adjacency is unchanged.

## 2. Edge density on 154 HNX nodes (11,781 unordered pairs)
| Criterion | Edges fired | Share of pairs |
|---|---|---|
| Linear `|rho| > 0.7` | 3 | 0.025% |
| Non-linear `lift > 1.7` | 12 | 0.102% |
| Either (combined) | 15 | 0.127% |
| Both | 0 | 0% |

Average off-diagonal degree 0.19; max degree 6; **142 of 154 nodes are singletons** (self-loop only). The
combined graph is near-empty: on thin HNX daily returns the `|rho| > 0.7` criterion fires on only 3 pairs and
the two criteria select disjoint pair sets (0 overlap), so the GAT operates on an almost fully disconnected
graph. Train rows used for the frozen graph: 4,129.

## 4. Diebold-Mariano (date-clustered, QLIKE)
| Comparison (A vs B) | p-value | favours | mean loss diff (A - B) |
|---|---|---|---|
| corr_lift_GAT vs no_graph_LSTM | 0.0037 | no_graph_LSTM | +0.00797 |
| corr_lift_GAT vs stat_GAT_vol2pk | 0.205 | stat (n.s.) | +0.00643 |
| stat_GAT_vol2pk vs no_graph_LSTM | 0.622 | no_graph (n.s.) | +0.00154 |

On the seed-ensembled forecast, the combined corr+lift edge is significantly WORSE than the no-graph LSTM at
h1 (DM p = 0.0037); it does not significantly differ from the shipped statistical edge (p = 0.205). The
statistical edge itself is statistically indistinguishable from no-graph (p = 0.622).

## 6. Paper-fidelity note (methodology gap)
The source paper predicts NORMALIZED PRICE for 10 US large-cap stocks with a single train/test split, no
validation set, no seed replication, and no Diebold-Mariano test. The present setup is a harder,
DM-tested, 154-node HNX daily-VOLATILITY forecast with a validation split, 3 seeds, seed ensembling, a
QLIKE positivity floor, and strict train-only edge freezing. The edge CONSTRUCTION follows the paper §3.2
faithfully (Pearson `|rho|>0.7` OR lift `>1.7`, verified against the published formulas by independent-recompute
tests); only the downstream task and evaluation rigor differ.

## 7. Conclusion
The combined corr+lift edge is the sixth graph edge to fail to beat a no-graph LSTM on HNX h1, following the
statistical vol->PK, sector ICB, MTGNN-learned, DY-spillover, and Graph-WaveNet-adaptive edges. On the
seed-ensembled DM basis it is significantly worse than no-graph (p = 0.0037). The direct cause is visible in
the edge density: on thin HNX daily returns the paper's `|rho|>0.7` criterion fires on 3 of 11,781 pairs and
the lift criterion on 12, leaving 142 of 154 nodes isolated — the GAT has almost no graph structure to
exploit, and the little it adds does not improve (and here degrades) the forecast. This is a consistent,
DM-tested robustness finding: across six distinct edge constructions, no graph edge improves HNX h1
volatility forecasting over the no-graph LSTM.
