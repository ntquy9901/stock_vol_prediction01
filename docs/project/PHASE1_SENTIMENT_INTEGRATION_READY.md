## What Has Been Prepared (Code Ready, Not Applied)

### Architecture A: Early Fusion (Sentiment as Node Features)

**Changes Made:**

1. **Sentiment Feature Engineering** (`src/sentiment/processing/sentiment_integration.py`)
   - Creates 3 sentiment features per stock per day:
     - `sentiment_score_3d`: Weighted average sentiment over 3-day window
     - `sentiment_confidence`: Mean confidence score from model
     - `news_count_norm`: Number of articles normalized [0, 1]
   - Aligns with HAR dataset dates
   - Outputs: `data/processed/sentiment_features/{ticker}_sentiment_aligned.csv`

2. **LSTM-GNN Config** (`src/lstm_gat_hybrid/config.py`)
   - Changed: `num_features_per_stock: 3 → 6`
   - Input: HAR (3) + Sentiment (3) = 6 features per stock

3. **Dataset Injection** (`src/lstm_gat_hybrid/dataset_with_graph_method.py`)
   - Added parameters: `load_sentiment`, `sentiment_dir`
   - Injects sentiment into GAT node features (Early Fusion)
   - Input shape: `[seq_len, num_stocks, 3]` → `[seq_len, num_stocks, 6]`

4. **Model Auto-Adapts** (`src/lstm_gat_hybrid/model_parallel.py`)
   - GAT first layer automatically accepts `num_features_per_stock` (now 6)
   - No code changes needed
